# Storyboard import illustrations

`assistant.png` and `external.png` were generated locally with ComfyUI and
Z-Image Turbo on 21 September 2026. The exact prompts, seeds and generation
settings are in `comfyui_workflow.json`. No hosted image API was used.

The source chooser uses both illustrations. The external prompt editor reuses
`external.png` in its header. The PNGs are bundled through the existing assets
packaging rule.
