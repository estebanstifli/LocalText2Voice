# LocalText2Voice 2.1.1

## Release scope

LocalText2Voice 2.1.1 strengthens the long-form Video Storyboard workflow and
improves how narration is prepared for local TTS engines. It focuses on making
large projects easier to control, recover and review without discarding valid
work after a temporary provider error.

## Highlights

- Import or edit a timed storyboard directly from TXT, SRT or VTT prompts.
- Validate timestamps before applying them, keep unchanged generated media and
  undo or redo the timeline replacement.
- Use complete external prompts without automatically injecting project style,
  narration context or negative-prompt rules.
- Align scene proposals against their actual source passages, handle repeated
  dialogue safely and make approximate timings visible.
- Resume compatible analyses and visual prompt batches after interruption while
  retaining validated prompts, media and review data.
- Configure cancellable retries for temporary Ollama and LiteLLM failures.
- Select image quality on supported image APIs and control full-video rendering
  from a progress dialog.
- Create more natural narration chunks by grouping short dialogue turns while
  preserving markup-driven voice changes and pauses.
