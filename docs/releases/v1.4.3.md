# LocalText2Voice 1.4.3

LocalText2Voice 1.4.3 is a maintenance release focused on preserving existing
AI assets, making optional-engine selection safer, and improving feedback while
models are loaded into shared memory.

## Highlights

- Automatically recovers models, imported voices, and Voice Gallery metadata
  from the legacy nested `data/data` location. Recovery is cancellable,
  non-destructive, and keeps the original directory as a backup.
- Prevents an optional local TTS engine from becoming active before it is
  installed. Once installation succeeds, the app refreshes and selects it.
- Shows visible progress and accurate loading/unloading states while local TTS
  engines move into or out of shared memory.
- Relocates saved reference-audio and gallery paths during legacy asset
  recovery so existing voices remain usable.
- Includes the new migration and engine-memory messages in all eleven UI
  languages.

## Windows

Download `LocalText2Voice-Setup.exe` below. The installer includes Piper,
FFmpeg, the shared Python runtime, the desktop app, the persistent engine host,
and the MCP stdio server. Larger AI models remain optional downloads managed
from the application.

The accompanying `.sha256` file can be used to verify the installer download.
