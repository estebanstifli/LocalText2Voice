# LocalText2Voice 2.0.2

LocalText2Voice 2.0.2 is a Windows maintenance release that fixes the startup
failure reported in issue #24.

## Highlights

- Prevents Poppler ICU DLLs from being collected by the Windows PyInstaller
  build when another tool has modified `PATH`.
- Validates the portable bundle before compiling the installer.
- Removes the incompatible ICU files from installations upgraded from 2.0.1.
- Preserves user settings, projects, downloaded engines and models during the
  upgrade.

## Windows download

Download `LocalText2Voice-Setup.exe` below. The matching `.sha256` file contains
the SHA-256 checksum for verifying the installer.
