# LocalText2Voice 1.4.2

LocalText2Voice 1.4.2 is a focused maintenance release for optional-engine readiness, AI asset storage compatibility, voice selection, and dark-theme markup editing.

## Highlights

- **Chatterbox repair detection:** incomplete dependency installations are no longer accepted solely because an install manifest exists.
- **Legacy storage recovery:** paths ending in the managed `data` directory, including older `data/data` references, resolve to the existing models and voices instead of creating a duplicate tree.
- **Safer voice workflow:** voices from an uninstalled local engine remain discoverable but cannot be selected or tested until that engine is ready.
- **Reliable engine selection:** the chosen TTS engine is saved immediately, and choosing another engine skips an obsolete pending OmniVoice setup bundle.
- **Better dark mode:** markup buttons, delimiters, strings, bracket commands, and validation errors now use readable dark-theme colors.
- **Localized guidance:** engine-readiness messages are available in all eleven interface languages.

## Windows Download

Download `LocalText2Voice-Setup.exe` from the assets below. The installer contains the desktop application, embedded Python runtime, Piper, and FFmpeg. Large optional engines and AI models are downloaded only when selected by the user.

Windows 10/11 x64 is supported. This release is currently unsigned, so Windows SmartScreen may show a warning on first launch.

Use the accompanying `LocalText2Voice-Setup.exe.sha256` file to verify the installer before running it.
