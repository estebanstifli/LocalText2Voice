# LocalText2Voice 1.5.1

LocalText2Voice 1.5.1 is a maintenance release focused on reliable Audio Mix
lengths, predictable voice selection, clearer output names, and broader
OmniVoice language support.

## Highlights

- Stop long non-looping background tracks at the end of the narration and its
  configured music tail instead of exporting unwanted music-only audio.
- Name final mixes from the audiobook project and add safe numbering when the
  destination already exists.
- Prioritize exact voice IDs and display names before descriptions, styles,
  tags, and fuzzy matches.
- Select Hindi directly in OmniVoice or type any language name or ISO code
  supported by the engine.
- Use the additional bundled ambient track `To the gates of Eleusis` by
  SamuelFJohanns, distributed under the Pixabay Content License.
- Use the new OmniVoice language guidance in all eleven supported UI
  languages.

## Windows

Download `LocalText2Voice-Setup.exe` below. The installer includes Piper,
FFmpeg, the shared Python runtime, the desktop app, the persistent engine host,
and the MCP stdio server. Larger AI models remain optional downloads managed
from the application.

Use `LocalText2Voice-Setup.exe.sha256` to verify the installer download.

An NVIDIA GPU is optional. Lightweight local engines can run on CPU, while
larger engines may be considerably faster on a compatible CUDA GPU.
