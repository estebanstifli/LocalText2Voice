# LocalText2Voice 2.0.1

LocalText2Voice 2.0.1 adds the Video Storyboard beta and EPUB book import,
while improving project persistence, image/video workflows and Review
regeneration.

## Highlights

- Import DRM-free EPUB 2/3 books in reading order with metadata, chapters and
  cover support for M4B export.
- Analyze audiobook narration and turn it into editable storyboard scenes.
- Discover characters, locations and appearance changes, review continuity and
  align scenes with narration timing.
- Generate or import images, use 50 bundled visual styles, edit images, create
  video clips and render an MP4 with the audiobook audio.
- Configure local Ollama/LiteLLM analysis, ComfyUI workflows and optional
  Runpod image/video generation.
- Store storyboard data and media references atomically and manage optional
  temporary reference storage.
- Reuse the persistent Engine Host when regenerating Review segments and apply
  Qwen Voice Library selections consistently.

Video Storyboard is beta software. Generated characters, continuity, timing,
images and clips require human review. Remote providers may incur costs and
their availability depends on the user's configuration.

## Windows

Download `LocalText2Voice-Setup.exe` below. The installer includes Piper,
FFmpeg, the shared Python runtime, the desktop app, the persistent engine host,
and the MCP stdio server. Larger TTS, analysis, image and video assets remain
optional downloads managed from the application.

Use `LocalText2Voice-Setup.exe.sha256` to verify the installer download.
