# LocalText2Voice 1.5.0

LocalText2Voice 1.5.0 expands the long-form generation workflow with
multi-format audiobook export, professional M4B metadata, and a resumable bulk
production queue.

## Highlights

- Export M4B, MP3, M4A, Opus, FLAC, or OGG with format-specific quality
  presets.
- Embed book metadata, cover art, and named chapters in M4B audiobooks.
- Rename projects inline and update M4B properties without rerunning TTS.
- Import multiple TXT books into Bulk Audiobooks, create separate editable
  projects, and render the queue sequentially with pause, resume, cancel,
  retry, recovery, and per-book progress.
- Choose a cover and background track per bulk book, or create projects now
  and generate them later.
- Use Qwen CustomVoice 0.6B and Base 1.7B as separate engine entries. Base 1.7B
  can reuse the default Harold Voice Gallery reference.
- Load complete Qwen snapshots locally, including nested tokenizer assets,
  and keep synthesis offline after installation.
- Use every new UI label and message in all eleven supported interface
  languages.

## Compatibility

Generation, review, subtitles, Audio Mix, HTTP, and MCP return the selected
audio format and MIME type. Existing integrations can continue reading the
deprecated `clean_mp3` and `mix_mp3` aliases during migration.

## Windows

Download `LocalText2Voice-Setup.exe` below. The installer includes Piper,
FFmpeg, the shared Python runtime, the desktop app, the persistent engine host,
and the MCP stdio server. Larger AI models remain optional downloads managed
from the application.

Use `LocalText2Voice-Setup.exe.sha256` to verify the installer download.
