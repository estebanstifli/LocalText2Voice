# LocalText2Voice 2.1.0

This file records the scope and verification of the 2.1.0 feature release.

## Positioning

LocalText2Voice has grown from a long-form TTS application into a free,
open-source AI production tool for audiobooks, podcasts, documentaries, films,
illustrated lessons and animated stories. The central workflow now combines
script preparation, local or remote narration, review, audio mixing and an
editable Video Storyboard that can produce a long-form MP4.

## Main 2.1.0 changes

- Video Storyboard analysis for scenes, characters, locations, eras and objects.
- Persistent references, appearance states, richer prompts and continuity tools.
- Batch image/video generation, cancellation, recovery and clearer provider
  diagnostics for long-running jobs.
- Direct provider adapters for Alibaba Cloud Wan, LTX, MiniMax H3 and BytePlus
  Seedance, in addition to existing ComfyUI, Runpod and LiteLLM routes.
- Transition controls, video settings, frame/video dialogs and localization
  updates.
- Qwen3 TTS loader compatibility fix and runtime package/path diagnostics.
- FFmpeg handling improvements for generated storyboard media.
