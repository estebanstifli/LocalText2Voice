# LocalText2Voice 1.4.4

LocalText2Voice 1.4.4 replaces the basic reference-audio import flow with a
complete, localized voice-cloning workspace.

## Highlights

- Clone voices for Chatterbox, OmniVoice, and F5-TTS Russian from uploaded
  audio, a selected microphone, or a system-audio loopback source.
- Record directly in the app with a live level meter, playback controls, and
  guidance for clean 3-20 second reference samples.
- Optionally transcribe samples locally with Faster Whisper, while retaining
  full manual control over the exact reference transcript.
- Accept WAV, MP3, FLAC, M4A, OGG, OPUS, AAC, and WEBM input and normalize the
  selected sample to an engine-compatible WAV file.
- Use every new cloning label, status, validation, and help message in all
  eleven supported UI languages.

## Windows

Download `LocalText2Voice-Setup.exe` below. The installer includes Piper,
FFmpeg, the shared Python runtime, the desktop app, microphone and WASAPI
loopback capture support, the persistent engine host, and the MCP stdio server.
Larger AI models remain optional downloads managed from the application.

Use `LocalText2Voice-Setup.exe.sha256` to verify the installer download.
