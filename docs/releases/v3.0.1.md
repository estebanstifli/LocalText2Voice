# LocalText2Voice 3.0.1

This maintenance release focuses on recovering long narration jobs, download
authentication and predictable project output folders.

## Continue Without Starting Over

When a project already has audio, Generate offers **Continue generation**,
**Regenerate all**, or **Cancel**. Continue checks existing recordings against
the text, voice, synthesis and segment postprocessing settings. It regenerates
only pending, failed, changed, missing or invalid segments.

Completed segments survive an interrupted job and reopening the project. If
everything matches, only the export is rebuilt. A failed replacement does not
overwrite the previous valid WAV. Review cannot rebuild an incomplete project
using stale recordings.

Older recordings without signatures are checked against their saved effective
configuration and WAV validity before being upgraded. Their original reference
file metadata cannot be reconstructed retroactively; use Regenerate all if that
reference was replaced since the original recording.

## Download And Settings Improvements

- **audio.cpp v0.9.5:** pinned, SHA-256 checked runtime packages; existing GGUF
  weights remain usable. CPU/CUDA/Vulkan downloads remain optional on Windows.
  An installation using v0.9.1 needs the new runtime: use Install for its model in
  Settings > TTS Engines. Existing valid model weights are verified and reused.
- **Hugging Face authentication:** optional read token in Settings > Advanced,
  applied to new Python engine/download processes without restarting Engine Host.
  Supported: Chatterbox, Qwen, OmniVoice, F5-TTS Russian, IndexTTS and Faster Whisper.
  The token is stored locally in `config.json` (not encrypted), masked in the UI,
  excluded from portable project settings and redacted from MCP settings responses.
  Clear it to use external authentication. Public downloads do not require it.
- **Output folder correction:** legacy paths inside the active project resolve
  to relative paths before UI initialization. New projects no longer inherit that
  older project's export directory. Explicit absolute paths are preserved.
- **11 UI languages:** translated generation choices and authentication help.

Empty WAV synthesis still has three attempts total; this limit is independent
of Whisper review retries. Export format/pause changes alone do not require new
speech synthesis. Existing Engine Host requests accept `generation_mode` set to
`resume` (default) or `regenerate`; this is not a new MCP tool.

## Windows Distribution

Download `LocalText2Voice-Setup.exe` and the accompanying SHA-256 checksum from
this release. The installer, uninstaller, application, MCP and Engine Host use
the maintainer's production Certum signing flow with RFC 3161 timestamps.
Publisher: **ESTEBAN GARCIA PEREZ**. No test certificate needs to be installed.
Signing does not guarantee SmartScreen reputation or antivirus results.

The base installer does not include optional TTS/Whisper models or audio.cpp
runtime packages. Existing projects, configuration and downloaded models should
be retained when upgrading; keep a backup of important projects.
