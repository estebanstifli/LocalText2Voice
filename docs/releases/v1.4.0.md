# LocalText2Voice 1.4.0

LocalText2Voice 1.4.0 expands local voice generation, Russian-language processing, and GPU control while keeping large AI models as optional downloads.

## Highlights

- **Qwen3-TTS Base 1.7B:** higher-capacity local voice cloning with reference audio and transcript support.
- **F5-TTS Russian:** optional Russian-focused voice cloning with a persistent worker and Silero Stress integration.
- **Two-stage Russian normalization:** deterministic handling of numbers, ordinals, percentages, currencies, abbreviations, and units, followed by optional stress-mark prediction for F5-TTS Russian.
- **Light and dark themes:** persistent application-wide theme selection with refreshed controls and progress dialogs.
- **Multi-GPU support:** detects multiple NVIDIA GPUs and lets the user choose the device used by compatible TTS engines and Faster Whisper.
- **Hardware-aware runtimes:** isolated CPU, CUDA 12.6, and CUDA 13 / PyTorch 2.11 dependency profiles, including newer NVIDIA Blackwell GPUs.
- **Improved engine management:** more stable selection, scrolling, model previews, cache handling, and memory lifecycle behavior.

## Windows Download

Download `LocalText2Voice-Setup.exe` from the assets below. The installer contains the application, embedded Python runtime, Piper, and FFmpeg. Large optional engines and AI models are downloaded only when selected by the user.

Windows 10/11 x64 is supported. This release is currently unsigned, so Windows SmartScreen may show a warning on first launch.

The accompanying `.sha256` asset can be used to verify the installer download.
