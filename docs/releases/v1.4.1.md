# LocalText2Voice 1.4.1

LocalText2Voice 1.4.1 is a reliability and workflow update for Russian text processing, reference voices, long-form chunking, Whisper review, and the persistent engine host.

## Highlights

- **Shared Russian pronunciation layer:** Silero Stress can now be installed once from Text Normalization and used with every TTS engine. F5-TTS Russian receives stress notation; other engines receive safe `Ё` spelling.
- **Safer long-form requests:** conservative per-engine chunk limits reduce malformed or unstable generations without blocking short phrases and previews.
- **Editable imported voices:** update metadata, replace normalized reference audio, or permanently delete user-imported voices while remote catalog entries remain protected.
- **Better voice previews:** pause, stop, and restart sample playback, plus open curated external voice resources from the Voice Library.
- **More reliable Review:** normalized Russian comparisons preserve raw Whisper transcripts and keep tail-analysis evidence tied to the current configuration.
- **Persistent engine-host hardening:** dedicated local ports, durable startup diagnostics, clean cancellation recovery, and safer shutdown behavior.

## Windows Download

Download `LocalText2Voice-Setup.exe` from the assets below. The installer contains the desktop application, embedded Python runtime, Piper, and FFmpeg. Large optional engines and AI models are downloaded only when selected by the user.

Windows 10/11 x64 is supported. This release is currently unsigned, so Windows SmartScreen may show a warning on first launch.

Use the accompanying `LocalText2Voice-Setup.exe.sha256` file to verify the installer before running it.
