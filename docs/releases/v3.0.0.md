# LocalText2Voice 3.0.0

Download the [signed Windows installer](https://github.com/estebanstifli/LocalText2Voice/releases/download/v3.0.0/LocalText2Voice-Setup.exe)
and its [SHA-256 checksum](https://github.com/estebanstifli/LocalText2Voice/releases/download/v3.0.0/LocalText2Voice-Setup.exe.sha256).
The installer is approximately 649 MiB; optional engines and weights download separately.

## Native local speech, with room to grow

3.0 introduces optional **audio.cpp** inference with **Higgs Audio v3 TTS 4B Q8**
and **Fish Audio S2 Pro Q8**, plus **Breeze TTS 2 Q8** and **VoxCPM 2**
(Q8, BF16 and Original). Runtime and weights download on demand; there is no
extra PyTorch environment for these engines and no multi-gigabyte models in the
base installer. Existing engines, audio-only projects and Video Storyboard remain.

- Shared persistent native runtime, Windows CPU/CUDA/Vulkan options and per-model
  settings, memory controls and GPU selection.
- Reference voices with transcripts from the gallery or your own recordings.
- Breeze and VoxCPM voice designers with preview and save-to-library workflows.
  Imported recordings are shared across compatible cloning engines, without
  duplicating their audio files.
- Model-specific emotion/instruction controls and VoxCPM diffusion settings.
  Direction is preserved on every VoxCPM chunk; Breeze vocal events remain intact.
- Native emotion/style/prosody/vocal controls in the editor, preserved through
  normalization and chunking. Higgs defaults to 200 characters, Fish to 400.
- Model/backend/reference arguments integrated into existing MCP generation tools.
- MCP instruction, guidance and diffusion arguments; responsive Engine Host
  preview requests, corrected installation state and native crash diagnostics.
- New Review Segment Detail editor for text, voice and synthesis parameters;
  regenerate and approve to replace audio, then rebuild the audiobook.
- Speed/volume applied during regeneration, improved Chatterbox Turbo tag handling,
  and updated translations across all 11 interface languages.

The previously unpublished 2.3.0 work is included: recoverable project-folder
renaming, relative/absolute exports, safer WAV replacement, Qwen Base reference
voices, background cache accounting and improved project loading.

## Additional Improvements

- Switch a Review segment to another installed local engine/model, with compatible
  settings retained and incompatible controls explained, without changing defaults.
- Design verified reusable voices from MCP with `design_voice` and inspect them
  with `get_voice`. Desktop designers use the same host service for previews/save.
- Voice design requires Faster Whisper small: only a matching normalized transcript
  is accepted. This is a speech consistency check, not a guarantee of voice style.
- Reference audio is stored at 24 and 48 kHz; Breeze/VoxCPM prefer the 48 kHz version.
- Empty WAV output is retried twice across engines before failing, without replacing
  existing audio. Audiobook rebuild validates all segment WAVs.
- Dialogue grouping suppresses automatic pauses across speaker changes, but always
  preserves explicit `{{pause ...}}` markup, including leading/trailing pauses.

## Important Notes

- Voice fixes: installed audio.cpp references appear in the markup menu without
  prior selection; deleted references no longer cause false name conflicts.
  Saving a designed voice offers overwrite, rename or cancel when its name exists.
- Storyboard fixes preserve clip timing when requested, propagate source duration
  and audio context, and tolerate transient Windows job-status file locks.
- audio.cpp is the direction for expanding the native catalog, not automatic
  support for every upstream model. More models require integration and tests.
- Model licenses apply separately. CPU may be slow; GPU support depends on drivers
  and hardware. Downloads are not RAM/VRAM requirements.
- Breeze targets English/Chinese and has non-commercial licensing restrictions;
  VoxCPM targets multilingual synthesis. See the catalog notices before use.
- Windows package validation does not imply Linux/macOS validation or new tests of
  every real model and GPU. Checks covered the package, GUI startup, MCP/Engine Host
  and a synthetic video render. A clean-PC install/uninstall was not repeated for
  this signed candidate.
- **Production signing:** the installer, uninstaller and all three project EXEs
  carry verified Certum signatures with SHA-256 and RFC 3161 timestamps. Windows
  publisher: **ESTEBAN GARCIA PEREZ**. No test certificate installation is needed.
  Earlier unsigned releases remain unchanged; SmartScreen/antivirus warnings are
  still possible. The old SignPath test workflow is retired.
- Finish running jobs and close the app and idle Engine Host before upgrading;
  restart desktop/MCP clients afterwards so they load the updated code.
