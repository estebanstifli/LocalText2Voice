# LocalText2Voice 2.1.2

This release improves large-audiobook export performance and brings the Video
Storyboard workflow to local AI clients through MCP, from scene authoring to
the final MP4 without opening the desktop UI.

## Highlights

- **57 new storyboard tools, 76 MCP tools in total.** Work with timed narration,
  styles, characters and appearance states, references, scenes, images, clips,
  contact-sheet previews and final rendering.
- **Persistent visual jobs.** Track progress and per-item results, cancel or
  retry work, inspect candidates and preserve earlier assets. Revision checks
  protect simultaneous edits from the app and an agent.
- **Faster preparation of large audiobooks (issue #27).** Each generated segment
  remains committed to SQLite, while full JSON snapshots and pause updates are
  batched. Matching silence files and WAV metadata are reused.
- **Honest progress reporting.** Synthesis, preparation, joining, encoding,
  mixing and finalization have separate progress. Phase estimates are not
  presented as an estimate for the entire remaining job.
- **Recovery and localization.** Recover pending project snapshots after an
  interruption, preserve external edits and show the new progress messages in
  all 11 UI languages.

## Updating

- MCP clients must use **stdio**. The old HTTP `/mcp` endpoint has been removed;
  HTTP remains the internal communication channel for EngineHost and the app.
- Let active jobs finish, then restart the app/idle EngineHost after updating
  so clients see the new routes and tools.
- Large-project snapshots are checkpoints. Before copying a project to another
  PC, finish/save it or reopen it after an interruption to recover pending
  SQLite changes into the portable project files.
- Optional Windows models and engine dependencies continue to install on demand.
  The standard Piper runtime/voices remain bundled; user-installed optional
  engines and models are excluded from the release.
